# Referências

Vídeos, prints e links de outros criadores enviados pelo painel (tela **Referências**). Cada um fica numa pasta
`AAAA-MM-DD_nome/` com `meta.yaml` (link, nota, status), os arquivos e `analise.md` (raio-X da IA).
"Incorporar ao app" leva os ganchos para o `docs/BANCO_HOOKS.md` e as ideias de efeito para `docs/IDEIAS_DO_APP.md`.
Vídeos e imagens ficam só no Mac (não vão para o GitHub).

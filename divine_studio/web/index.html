    Saúde do app

      Trazer o que já existe

      Importa os vídeos brutos e editados da pasta Divine Medical Spa Marketing: cada tema vira um projeto, "Pronto para postar" vai para a Galeria e a Programação, e as legendas e copies vêm junto. Nada é apagado nem movido; por padrão o app cria atalhos (não ocupa espaço). Rode no Mac.

      Biblioteca de vídeos

      Todos os vídeos criados e importados. Toque para assistir; "Editar" abre o projeto a qualquer momento.

      Laboratório viral

      Cada Reels é um teste de formato. O app vê o que viraliza lá fora (Radar), testa nos seus perfis, mede e decide o próximo teste.

      Testes desta semana

      um formato por dia; o app equilibra o que vence com o que ainda precisa testar

      Radar: o que está viralizando agora

      O app não roda robô no Instagram nem no TikTok (pode bloquear a conta). Use a API oficial ou a missão para o Claude no Chrome: ele navega no seu navegador, só olhando, e você cola o resultado aqui.

      Placar dos formatos

      Vitória = a peça foi melhor que a mediana do próprio perfil (alcance, envios, salvos, retenção e seguidores). Marque as peças como postadas e conecte o Instagram e o TikTok para o placar se alimentar sozinho.

      Caixa de entrada

      Solte vídeos do celular numa destas pastas (o Google Drive para computador sincroniza sozinho). Cada vídeo vira um projeto com 3 versões, cada uma testando um formato viral, e o storyboard para você aprovar.
